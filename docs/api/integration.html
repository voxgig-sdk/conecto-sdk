POST /integrations/{slug}/install/

Operation ID: installIntegration.

Authentication: bearer token (bearerAuth) or basic token (basicAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | slug | path | string | Yes | Integration slug. |

Request body

application/json

Property Type Required Description
actions array of string No Allowlist of action names.
widget_ids array of integer No

Responses

200: Success

application/json

Property Type Required Description
actions array of object No Actions this integration exposes.
actions[].name string Yes Action name, for example orders.get_status.
actions[].path string No Path appended to base_url.
actions[].risk enum: public_read, verified_read, public_write, write No Identity requirement. public_read needs no identity; verified_read requires a verified visitor email; write is a mutation on a verified account and is never silently retried.
auth_type string No How Conecto authenticates to base_url.
base_url string (uri) Yes Root URL Conecto POSTs actions to.
name string Yes Human-readable name.
signing_secret string No Secret used to sign action calls. Returned on create and on read, and replaced by rotate_signing_secret.
slug string Yes Stable identifier, used in the path.
