Make your first API call

  1. Choose an SDK from the SDK section and follow its installation instructions.
  2. Configure the API server and authentication settings.
  3. Open the Action reference and supply the parameters and request body it requires.
  4. Call create and inspect the returned entity data.

The first endpoint is POST /integrations/{slug}/actions/{action}/run/. Request and response examples come from the API specification.
